## Vue d'ensemble

Cette base de connaissances compile des faits techniques fréquents sur les chaudières gaz murales et au sol (atmosphériques, basse température, condensation), couvrant les marques principales :

- **Saunier Duval** (ThemaPlus, Isotwin, Duomax)
- **Vaillant** (ecoTEC, turboTEC, atmoTEC)
- **Frisquet** (Prestige, Hydromotrix)
- **De Dietrich** (City, MCX, Naneo)
- **Atlantic** (Perfinox, Idra)
- **Chaffoteaux** (Talia, Pigma, Alixia)
- **Elm Leblanc** (Egalis, Acleis, Megalis)

Chaque **FACT** décrit les symptômes, les causes racines probables, une procédure de résolution pas-à-pas et des mesures préventives à intégrer dans les plans de maintenance.

**Sources :** Documentation constructeurs, CEGIBAT GRDF, Guides techniques d'entretien, Retours terrain techniciens agréés.

## Comment utiliser cette base

1. Consultez le fichier correspondant à la catégorie de panne
2. Recherchez le FACT correspondant aux symptômes observés
3. Suivez les étapes de résolution dans l'ordre
4. Appliquez les mesures préventives recommandées
5. Consignez l'intervention dans le carnet d'entretien

---

**Note :** Cette documentation est destinée aux techniciens qualifiés. Toute intervention sur une chaudière gaz doit être réalisée par un professionnel habilité conformément à la réglementation en vigueur.
